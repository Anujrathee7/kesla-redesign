# Kesla website redesign

An independent redesign concept of kesla.com, built in Next.js with English and Finnish. It keeps
Kesla's own look (yellow, black, Exo and the cut corners) and cleans up the layout page by page:
home, products, timber cranes, a product page, dealers, contacts, company, references, news and
career.

Live: https://kesla-redesign.vercel.app

Unaffiliated concept work. The photography and product content belong to Kesla Oyj.

```bash
npm install
npm run dev
```
